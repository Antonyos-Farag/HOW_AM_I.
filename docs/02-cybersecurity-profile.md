## 🎯 Core Cybersecurity Focus

Cybersecurity is my **primary professional direction**. I am developing practical skills through structured training, hands-on labs, technical projects, and independent investigation.

| 🛡️ Focus Pillar | 🔍 Specific Areas of Interest | 🎯 Operational Goal |
| :--- | :--- | :--- |
| **SOC Operations & Career Paths** | • Security Operations Center (SOC) operations<br/>• SOC Analyst and SOC Engineer career paths<br/>• SIEM monitoring, alert analysis, and security event investigation | Triage security alerts, manage SIEM pipelines, and investigate security incidents |
| **Network & Host Security** | • Network Security and Traffic Analysis<br/>• Windows Security, Sysmon, and Linux | Inspect packet traffic and analyze host-level Windows and Linux telemetry |
| **Threat Hunting, IR & DFIR** | • Threat Hunting and Incident Response<br/>• Digital Forensics and Endpoint Investigation | Proactively hunt threats, reconstruct timelines, and analyze endpoint artifacts |
| **Detection & Adversary Intel** | • Detection Engineering and security monitoring<br/>• Threat intelligence and adversary behavior | Author high-fidelity detection rules grounded in adversary TTPs |
| **Offensive & Red Team Perspective** | • Web Application Security and Penetration Testing<br/>• Red Team fundamentals and offensive security techniques | Understand attacker techniques to strengthen defensive detection and response |

> 🔄 **Connecting Offense and Defense:** I am particularly interested in connecting offensive security knowledge with defensive security operations, allowing me to understand both attacker techniques and how defenders can detect and investigate them.
